## Codex repository-switch protocol

When the official case/coding starts:

1. Open/clone **BAITC-Hacks/hack-7e4788ab-evomind**.
2. Read the official case/rules first.
3. Use **RollSatrs/HackAlemAi** only as reference for process/templates.
4. Copy/adapt only the documentation/process pieces that are allowed and still relevant.
5. Do NOT blindly copy traffic-specific assumptions or any pre-written solution.
6. Fill the official repo's case/requirements from the real hackathon case.
7. Create task branches in the official repo:
   - `adil/<task>`
   - `rollan/<task>`
   - `asanali/<task>`
8. All competition code, commits, PRs and final state stay in the official repo.
