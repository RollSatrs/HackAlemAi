# Preflight Checklist

Run this before the hackathon.

## Accounts / Access
- [ ] All 3 participants can access the official team GitHub repository.
- [ ] All 3 participants can push.
- [ ] All 3 participants have Codex working.
- [ ] All 3 Codex setups can read the team repository.
- [ ] Required HackAlem Telegram bot access works.
- [ ] OpenAI/API/Codex credentials required by the organizers are available.
- [ ] No secrets are committed.

## Git dry run
- [ ] Each participant clones the same repo.
- [ ] Each creates a branch.
- [ ] Each gives Codex a tiny task.
- [ ] Each commits and pushes.
- [ ] Integration/merge succeeds.
- [ ] Everyone pulls the merged state.
- [ ] A Handoff is written and read by another person.

## Repository
- [ ] `AGENTS.md` exists.
- [ ] `README.md` exists.
- [ ] `docs/CASE.md` exists.
- [ ] `docs/API_CONTRACT.md` exists.
- [ ] `.gitignore` is correct.
- [ ] `.env.example` exists if needed.
- [ ] Setup/run/test commands are known.
- [ ] Project starts on another teammate's laptop.

## Hardware / Network
- [ ] Laptop.
- [ ] Charger.
- [ ] LAN adapter if useful/required.
- [ ] Backup hotspot.
- [ ] Dependencies/cache available locally where practical.
- [ ] Git credentials tested.

## Demo safety
- [ ] Stable demo path.
- [ ] Backup screenshots.
- [ ] Backup video if permitted.
- [ ] Offline copy of key docs.
