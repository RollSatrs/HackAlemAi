# Архитектурные решения

Здесь фиксируются решения, затрагивающие несколько рабочих областей.

## 2026-09-22 — GitHub как единый командный источник правды

- **Решение:** Код, задачи, решения, handoff и журнал работ хранятся в официальном командном GitHub.
- **Причина:** Каждый участник и его Codex получают одинаковый контекст после fetch/pull.
- **Последствия:** Важные изменения сопровождаются обновлением Markdown/Issue/PR.
- **Затронутые области:** Весь репозиторий.

## 2026-09-22 — Роли команды

- **Әділ:** Frontend / Visualization.
- **Ролан:** Backend / Core / Optimization.
- **Асанали:** Testing / Integration / Demo / Presentation.
- **Правило:** одна задача — один основной владелец.

## 2026-09-22 — Contract-first

- **Решение:** До параллельной реализации frontend/backend фиксировать минимальный API/data contract.
- **Причина:** Frontend может работать на mocks, Backend — на реальной реализации, Testing — проверять один и тот же контракт.
- **Последствия:** Изменение контракта документируется до того, как зависимые части продолжат работу.

## 2026-09-22 — Traffic только sandbox

- **Решение:** EVOLVE AI / adaptive optimization — общая концепция; traffic lights — подготовительный пример.
- **Причина:** Реальный кейс трека будет иметь приоритет.
- **Последствия:** После выдачи кейса сначала заполняется `CASE.md`, затем адаптируется архитектура.

## 2026-09-22 — Осторожный режим по заранее написанному коду

- **Решение:** До прямого подтверждения организаторов не считать разрешённой схему «написать финальный solution-code заранее локально и залить после старта».
- **Причина:** Публичные инструкции требуют вести разработку в командном репозитории и фиксировать прогресс.
- **Последствия:** До старта готовим доступы, docs, workflow, templates, dry run и изучение технологий; конкурсную реализацию начинаем после официального кейса/старта.

## 2026-09-22 — Git-разрешения для Codex

- **Решение:** Codex может самостоятельно выполнять `git add`, `git commit` и обычный `git push` после доступных проверок. `force-push` запрещён; merge выполняется по процессу команды.
- **Причина:** Снять ручной шаг публикации, сохранив защиту истории.

## 2026-09-22 — Единый регламент Codex

- **Решение:** Корневой `AGENTS.md` — единый обязательный регламент; локальные `AGENTS.md` только дополняют его правилами роли.
- **Причина:** Каждый Codex должен одинаково понимать порядок работы, Git-разрешения и Definition of Done.
- **Последствия:** Общие правила меняются в корневом `AGENTS.md`; межзонные изменения также фиксируются здесь.
- **Затронутые области:** Весь репозиторий.
