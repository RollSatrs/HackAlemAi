# Архитектурные решения

Здесь фиксируются только решения, затрагивающие несколько рабочих областей.

## 2026-09-22 — GitHub-репозиторий как единый источник правды

- **Решение:** Хранить задачи, решения, handoff и журнал работ вместе с кодом.
- **Причина:** Каждый участник и его Codex получают одинаковый контекст после `git pull`.
- **Последствия:** Изменения задачи сопровождаются обновлением Markdown-документов.
- **Затронутые области:** Весь репозиторий.

## 2026-09-22 — Автономные commit и push

- **Решение:** Codex может самостоятельно выполнять `git add`, `git commit` и обычный `git push` после проверок. `force-push` и merge требуют отдельного разрешения.
- **Причина:** Снять ручной шаг публикации, сохранив защиту от перезаписывания истории и непроверенного слияния.
- **Последствия:** Разрешение действует для этого репозитория; системные запросы безопасности могут по-прежнему требовать подтверждения.
- **Затронутые области:** Git-процесс всего репозитория.
