# HackAlem Rules — Internal Safety Summary

This file is NOT a replacement for the official rules.

## Conservative working interpretation
Until the organizers explicitly confirm otherwise:

- Use the platform-created team GitHub repository for competition development.
- Keep competition progress visible in that repository.
- Use Codex as required by the event.
- Do not assume a pre-written final solution can be developed locally before the event and uploaded later.
- Generic preparation (accounts, tools, docs, workflow, templates, practice) is safer than pre-writing the final competition solution.

## Question to organizers
Ask directly:

> Can we have generic reusable boilerplate/modules written before the official start and move them into the platform-created team GitHub repository after the start? Or must all competition solution code be written after the coding window begins and committed directly to the official team repository? Are AGENTS.md, README templates, setup scripts and generic reusable libraries allowed in advance?

## Rule precedence
If any official HackAlem instruction conflicts with this repository:
**the official instruction wins.**
