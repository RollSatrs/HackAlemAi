# HackAlemAi

Общий тестовый репозиторий для командной разработки с Codex.

Актуальные задачи, решения и статус проекта хранятся в [`docs/`](docs/).

## Быстрый старт

1. Прочитайте [`AGENTS.md`](AGENTS.md) и `AGENTS.md` в своей рабочей области.
2. Проверьте [`docs/TASKS.md`](docs/TASKS.md), [`docs/DECISIONS.md`](docs/DECISIONS.md) и [`docs/HANDOFF.md`](docs/HANDOFF.md).
3. Выберите свободную задачу со статусом `Ready`.
4. Работайте в отдельной ветке и обновляйте проектную документацию.

> Имена и зоны ответственности двух участников ещё нужно уточнить. До этого `frontend/` и `shared/` считаются временными зонами.
